# 调研任务说明

围绕下面三个问题，调研 2026 年国内大模型推理定价的变化。时效性优先，尽量用最近 90 天的资料。

## 问题

1. 2026 年主流中文大模型 API 的输入/输出单价大致在什么区间？
2. 缓存命中与批处理这两类折扣，实际能省多少？有哪些前提条件？
3. 自建推理（vLLM / SGLang）在什么规模下比 API 更划算？

## 要求

- 至少 6 个来源，其中至少 3 个一手来源（厂商定价页、官方发布说明、项目文档）。
- 只引用运行期真实抓取成功的页面，不要凭记忆写 URL。
- 不确定的结论标注「推断」。
- 输出 1500-2500 字中文报告，事实性结论带脚注。
